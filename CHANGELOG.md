# Changelog

## 0.1.0 — release candidate

- Sky-coordinate TESSCut coverage inventory with distinct no-coverage and query-failure states.
- Optional all-sector eleanor extraction with fixed/custom apertures and TessCut mode.
- Standard correction by default; optional PCA; raw photometry retained.
- Cadence-aware unweighted Lomb–Scargle power spectra and candidate single-frequency fits.
- Per-sector outputs and manifests instead of mislabeling the last sector as a merged light curve.
- Tests, documentation, citation metadata and GitHub Actions.

This is not a validated stable release or a claim of live archive compatibility.
