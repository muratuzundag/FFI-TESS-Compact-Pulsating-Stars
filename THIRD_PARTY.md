# Third-party software and attribution

This repository contains original wrapper code informed by the owner's supplied
`search_target_FFI.py`, `FFI.py` and `LSP.py`. Their private paths and invalid
legacy analysis sections are not copied into the public package. Confirm rights
for any coauthored contributions before publication.

No eleanor or other dependency source is vendored. eleanor is an independent
MIT-licensed package: https://github.com/afeinstein20/eleanor
The local package is a custom workflow/profile, not a fork, endorsed release,
or a claim that upstream eleanor was specially validated for compact pulsators.
Upstream package licenses, citations and data acknowledgments still apply.

Follow the current eleanor citation guidance for Feinstein et al. (2019),
tess-point (Burke et al. 2020), and TessCut (Brasseur et al. 2019), alongside
TESS/SPOC, MAST, Astropy, Astroquery, NumPy, SciPy and Matplotlib as applicable.
This workflow forces TessCut mode. It does not use precomputed eleanor-lite
light curves, so it does not claim analysis of that catalog.

No NASA, ESA, STScI, MAST or eleanor team affiliation or endorsement is implied.
